§ 5.1

Random Sampling

พื้นฐานของ statistical inference คือการแยกแยะระหว่าง ประชากร (Population) และ ตัวอย่าง (Sample) รวมถึง พารามิเตอร์ และ สถิติ

▶ POPULATION (ประชากร)
Definition 5.1

ข้อมูลทั้งหมดที่เราสนใจศึกษา ขนาด N

μ = ΣXᵢ / N ← ค่าเฉลี่ย σ² = Σ(Xᵢ–μ)² / N ← ความแปรปรวน ρ ← พารามิเตอร์
▶ SAMPLE (ตัวอย่าง)
Definition 5.2

ส่วนย่อยของประชากร ขนาด n

X̄ = ΣXᵢ / n ← ค่าเฉลี่ย S² = Σ(Xᵢ–X̄)²/(n–1) ← ความแปรปรวน ρ̂ ← สถิติ (statistic)
Definition 5.3 — Parameter

ฟังก์ชันใดๆ ของข้อมูลทั้งหมดในประชากร เช่น μ, σ², σ, ρ

Definition 5.4 — Statistic

ฟังก์ชันใดๆ ของตัวแปรสุ่มที่ประกอบเป็นตัวอย่าง เช่น X̄, S², S, ρ̂

จุดสำคัญ: Parameter คือค่าคงที่ (แต่มักไม่ทราบ) | Statistic คือตัวแปรสุ่มที่เปลี่ยนตามตัวอย่าง และใช้ประมาณ parameter

เปรียบเทียบ Parameter vs Statistic

ลักษณะParameter (ประชากร)Statistic (ตัวอย่าง)
ค่าเฉลี่ยμ = ΣXᵢ / NX̄ = ΣXᵢ / n
ความแปรปรวนσ² = Σ(Xᵢ–μ)² / NS² = Σ(Xᵢ–X̄)² / (n–1)
ส่วนเบี่ยงเบนมาตรฐานσ = √σ²S = √S²
สัดส่วนρρ̂
ทราบค่าไม่ทราบ (ต้องการประมาณ)คำนวณจากตัวอย่างได้
§ 5.2

Some Important Statistics

สถิติตัวอย่างที่สำคัญ 5 ตัว: ค่าเฉลี่ย, มัธยฐาน, ฐานนิยม, พิสัย, และ ความแปรปรวน

Definition 5.5 — Sample Mean

ค่าเฉลี่ยตัวอย่าง X̄

X̄ = (X₁ + X₂ + ... + Xₙ) / n = ΣXᵢ / n
EXAMPLE 5.1 — ผู้ตรวจสอบสุ่มกระป๋องทูน่า 7 กระป๋อง

ข้อมูล: 1.8, 2.1, 1.7, 1.6, 0.9, 2.7, 1.8 (% สิ่งสกปรก)

x̄ = (1.8+2.1+1.7+1.6+0.9+2.7+1.8) / 7 = 12.6 / 7 = 1.8%
Definition 5.6 — Sample Median

ค่ามัธยฐาน (Median)

เรียงข้อมูลจากน้อยไปมาก แล้วหาค่ากลาง

n คี่ (odd)
Median = X[(n+1)/2]
n คู่ (even)
Median = (X[n/2] + X[n/2+1]) / 2
EXAMPLE 5.3 — นิโคติน 6 มวน (mg)

เรียง: 1.9, 2.3, 2.5, 2.7, 2.9, 3.1

Median = (2.5 + 2.7) / 2 = 2.6 mg
Definition 5.7 — Mode

ฐานนิยม

ค่าที่ปรากฏบ่อยที่สุด อาจไม่มีหรือมีหลายค่าก็ได้

unimodal bimodal no mode
Ex 5.4: {9,10,5,9,9,7,8,6,10,11} → mode = $9
Ex 5.5: {2,0,3,1,2,4,2,5,4,0,1,4} → bimodal = 2 & 4
Definition 5.8 — Range

พิสัย (Range)

Range = X(n) – X(1)

ความแตกต่างระหว่างค่าสูงสุดและต่ำสุด

Ex 5.7: IQ = {108,112,127,118,113}
Range = 127 – 108 = 19
Definition 5.9–5.10 — Variance & Std. Deviation

ความแปรปรวน และส่วนเบี่ยงเบนมาตรฐาน

S² = Σ(Xᵢ – X̄)² / (n–1) วิธีลัด (Theorem 5.1): S² = [n·ΣXᵢ² – (ΣXᵢ)²] / [n·(n–1)] S = √S²
ทำไมหารด้วย (n–1)? เพื่อให้ S² เป็น unbiased estimator ของ σ² เรียกว่า "Bessel's correction"
EXAMPLE 5.8 — จำนวนปลาเทราต์: 3, 4, 5, 6, 6, 7 (n=6)
ΣXᵢ = 31, ΣXᵢ² = 171, n = 6 S² = [(6)(171) – (31)²] / [(6)(5)] = [1026 – 961] / 30 = 65/30 ≈ 2.167

§ 5.3

Sampling Distributions of Means

เมื่อสุ่มตัวอย่างซ้ำๆ จากประชากร ค่า X̄ จากแต่ละตัวอย่างจะมีการแจกแจงของตัวเอง เรียกว่า Sampling Distribution of the Mean

Theorem 5.2 — คุณสมบัติของ X̄

ถ้าสุ่มตัวอย่างขนาด n จากประชากรที่มีค่าเฉลี่ย μ และความแปรปรวน σ²

ค่าเฉลี่ยของ X̄
E(X̄) = μ
X̄ เป็น unbiased estimator ของ μ
ความแปรปรวนของ X̄
Var(X̄) = σ²/n
ยิ่ง n มาก → ยิ่งแม่นยำ
Theorem 5.3 & 5.4 — Central Limit Theorem

CLT — กฎหลักที่สำคัญที่สุด

Z = (X̄ – μ) / (σ/√n) ~ N(0,1) ใช้ได้เมื่อ: • ประชากรปกติ → ทุกขนาด n • ประชากรใดๆ → n ≥ 30 (CLT)
CLT: ไม่ว่าประชากรจะมีรูปแบบใด ถ้า n มากพอ การแจกแจงของ X̄ จะเข้าสู่ Normal เสมอ — นี่คือเหตุผลที่ Normal distribution สำคัญมาก

§ 5.4

Sampling Distribution of X̄₁ – X̄₂

เมื่อต้องการเปรียบเทียบ สองกลุ่ม ที่เป็นอิสระต่อกัน

Definition 5.12–5.13 — ผลต่างของสองค่าเฉลี่ย
E(X̄₁ – X̄₂) = μ₁ – μ₂ Var(X̄₁ – X̄₂) = σ₁²/n₁ + σ₂²/n₂ Z = [(X̄₁–X̄₂) – (μ₁–μ₂)] / √(σ₁²/n₁ + σ₂²/n₂) ~ N(0,1) เงื่อนไข: ทั้งสองประชากรปกติ หรือ n₁≥30 และ n₂≥30
Example 5.13

กลุ่ม 1: μ₁=80, σ₁=5, n₁=25 | กลุ่ม 2: μ₂=75, σ₂=3, n₂=36
P(3.4 ≤ X̄₁–X̄₂ ≤ 5.9) = ?

1
μ₁–μ₂ = 5
SE = √(25/25 + 9/36) = √1.25 ≈ 1.118
2
Z₁=(3.4–5)/1.118=–1.43
Z₂=(5.9–5)/1.118=0.80
3
P = 0.7881–0.0764 = 0.7117
Example 5.14

A: μ=6.5, σ=0.9, n=36 | B: μ=6.0, σ=0.8, n=49
P(X̄_A – X̄_B ≥ 1) = ?

1
n₁=36≥30, n₂=49≥30 → CLT ใช้ได้

χ² Distribution

ใช้สำหรับอนุมานเกี่ยวกับ ความแปรปรวน σ² ของประชากร

Theorem 5.5 — Chi-squared Distribution

ถ้า S² คือความแปรปรวนตัวอย่างจากประชากรปกติที่มีความแปรปรวน σ²

χ² = (n–1)S² / σ² = Σ(Xᵢ–X̄)² / σ² มีการแจกแจง Chi-squared ด้วย ν = n–1 degrees of freedom ใช้ได้เมื่อ: ประชากรมีการแจกแจงปกติ
ลักษณะของ χ²: ค่า ≥ 0 เสมอ | เบ้ขวา | รูปร่างขึ้นกับ ν | ยิ่ง ν มาก → ยิ่งใกล้ Normal
Example 5.15 — อายุแบตเตอรี่รถยนต์

ประชากรปกติ, σ²=0.2 year², n=25 → P(S² < 0.3035) = ?

1
แปลง S² เป็น χ²:
P(S²<0.3035) = P[(n–1)S²/σ² < (24)(0.3035)/0.2]
2
= P[χ²(24) < 36.42]
3
= 1 – P[χ²(24) > 36.42] = 1 – 0.05 = 0.95
P(S² < 0.3035) = 0.95 → ความน่าจะเป็น 95%

§ 5.6

t-Distribution

t-Distribution

ใช้เมื่อ ไม่รู้ σ² และ n < 30 โดยใช้ S² แทน

Theorem 5.6 — t-Distribution
T = Z / √(V/ν) โดย Z~N(0,1), V~χ²(ν) ในทางปฏิบัติ: T = (X̄ – μ) / (S/√n) ~ t(ν = n–1) ใช้เมื่อ: ไม่รู้ σ, n < 30, ประชากรปกติ สมมาตรรอบ 0 เหมือน Z แต่หางหนักกว่า เมื่อ n→∞ → เหมือน N(0,1)
สมมาตร: t(1–α, ν) = –t(α, ν)

เมื่อไหรใช้ Z และ t?

เงื่อนไขใช้สูตรการแจกแจง
รู้ σ (ทุก n) หรือ n≥30Z = (X̄–μ)/(σ/√n)N(0,1)
ไม่รู้ σ, n<30, Normal populationT = (X̄–μ)/(S/√n)t(ν=n–1)

§ 5.7

F-Distribution

F-Distribution

ใช้เปรียบเทียบ ความแปรปรวนสองกลุ่ม ที่เป็นอิสระต่อกัน

Theorem 5.7–5.9 — F-Distribution
F = (U/ν₁) / (V/ν₂) โดย U~χ²(ν₁), V~χ²(ν₂) อิสระกัน ในทางปฏิบัติ (Theorem 5.9): F = (S₁²/σ₁²) / (S₂²/σ₂²) ~ F(ν₁=n₁–1, ν₂=n₂–1) คุณสมบัติสำคัญ (Theorem 5.8): f(1–α)(ν₁,ν₂) = 1 / f(α)(ν₂,ν₁) ใช้ได้เมื่อ: ทั้งสองประชากรปกติ
Example 5.17 — ค่า F critical
a) f₀.₉₅(6,10) = 1/f₀.₀₅(10,6) = 1/4.06 = 0.246 b) f₀.₉₉(11,7) = 1/f₀.₀₁(7,11) = 1/4.89 = 0.2045
Example 5.18 — σ₁²=10, σ₂²=15

n₁=25, n₂=31, ν₁=24, ν₂=30
P(S₁²/S₂² < 1.26) = ?

1
P(S₁²/S₂²<1.26) = P[F<1.26×(15/10)]
2
= P[F(24,30) < 1.89]
3
= 1–0.05 = 0.95
